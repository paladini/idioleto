# Changelog

All notable changes to this project are documented in this file.

The format follows Keep a Changelog, and this project uses semantic versioning
once releases begin.

## [0.1.0] - Unreleased

### Added

- Initial Python package and `idioleto` CLI.
- `.idiolect` JSON Schema and Pydantic contracts.
- `idioleto compile` for Markdown, text, and PDF corpora.
- Lightweight stylometric analysis and semantic anchor selection.
- Prompt compiler for local LLM system prompts.
- Ollama-backed `idioleto generate`.
- Tests, examples, CI, and community documentation.
